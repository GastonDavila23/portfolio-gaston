---

## 🛠️ Stack Tecnológico

Este portafolio fue construido desde cero aplicando las mejores prácticas del desarrollo web moderno:

* **Framework:** [Next.js](https://nextjs.org/) (App Router)
* **Lenguaje:** [TypeScript](https://www.typescriptlang.org/) en modo estricto
* **Estilos:** [Tailwind CSS v4](https://tailwindcss.com/) (Sistema de diseño propio con variables `@theme`)
* **Animaciones & Interactividad:** [Framer Motion](https://www.framer.com/motion/)
* **Iconografía:** [Lucide React](https://lucide.dev/)
* **Despliegue & Hosting:** [Vercel](https://vercel.com/)

---

## ✨ Características del Proyecto

* **Diseño UI/UX Premium:** Interfaz oscura (*Dark Mode*) con efectos de *Glassmorphism*, resplandores controlados y detalles sutiles inspirados en la identidad cromática de la marca.
* **100% Responsive & Accesible:** Optimizado para funcionar de forma fluida en dispositivos móviles, tablets y pantallas de escritorio.
* **Rendimiento Óptimo:** Configurado para alcanzar excelentes puntuaciones en Lighthouse (SEO, Rendimiento y Buenas Prácticas).
* **Arquitectura Modular:** Separación clara de componentes de interfaz, datos estáticos y lógica de estado.
